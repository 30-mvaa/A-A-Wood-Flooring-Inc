## 🚀 Key Features

1. **Frosted Glass Navigation Bar:** Sticky header with emergency estimate banner, authentic logo, smooth anchor links, mobile menu drawer, and direct call trigger.
2. **Cinematic Hero Section:** Statement headline, dual phone display, authentic herringbone installation photography, and flyer trust highlights.
3. **Interactive Project Cost Estimator:** Real-time square-footage slider and service selector that computes investment ranges and locks in estimates into the contact form.
4. **Comprehensive Services (8 Specialized Offerings):**
   - Hardwood Flooring (Unfinished, Pre-Finished, Engineered Wood)
   - Herringbone & Custom Geometric Patterns
   - Dustless Floor Sanding & Refinishing (HEPA containment)
   - Luxury Vinyl Plank (LVP) Flooring (100% Waterproof)
   - Precision Floor Repair & Board Weaving
   - Scraping & Buffing Maintenance (Screen & Recoat)
   - Custom Wood Staining & Color Swatching
   - Flooring Remodeling, Staircases & Baseboard Trims
   - *Interactive "Read More" modal detailing specs, process steps, and applications.*
5. **Interactive Before & After Slider:** Real-time draggable comparison showing dramatic sanding & stain restoration results.
6. **Editorial About Us Section:** 10+ years industry experience, authentic company flyer integration, and core credential statistics.
7. **Apple-Inspired Bento Grid (Why Choose Us):** 6 key pillars highlighting precision workmanship, zero-drift alignment, customer satisfaction, and licensed protection.
8. **Interactive Work Gallery & Lightbox:** Filterable portfolio with high-resolution photography, keyboard-navigable full-screen lightbox, and zoom effects.
9. **Authentic Testimonial Showcase:** 5.0-star rating summary and verified customer review cards.
10. **Service Areas Breakdown:** Detailed city and county coverage across NY, NJ, and CT with operating hours.
11. **Validated Estimate Request Form:** Instant input validation, error handling, property type toggles, and submission confirmation.
12. **Local SEO & Schema.org Structured Data:** Valid `HomeAndConstructionBusiness` JSON-LD schema, Open Graph metadata, Twitter Cards, `robots.txt`, and `sitemap.xml`.
13. **Floating Immediate Call Action Button:** One-tap emergency phone dialer and quote launcher.

## 🛠️ Technology Stack

- **Framework:** React 18 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Icons:** Lucide React + Custom Brand SVGs
- **Typography:** Apple System Font Stack (`-apple-system`, `SF Pro Display`, `Inter`)
- **SEO:** Schema.org JSON-LD LocalBusiness data, OpenGraph, Canonical tags
